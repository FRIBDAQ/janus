Description

CAEN FERS Library provides an interface to support, control and acquire data from the boards of FERS-5200 family.

Website

The official releases of this library can be found on the CAEN website, at https://www.caen.it/products/caen-ferslib-library/.

Language

The code is fully compliant with C99 (ISO/IEC 9899:1999) standard and, optionally, with C++17 (ISO/IEC 9899:2018) standard.
