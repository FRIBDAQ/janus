Enumerator
STARTRUN_ASYNC 

Run start sent to each board individually

STARTRUN_TDL 

Run start sent thorugh concentrator to all its board in sync and eventually propagate to cnc slaves

STARTRUN_TDL_EXTRUN 

Run start sent from external source (e.g. CNC LEMO) and eventually propagate to cnc slaves. The system is armed

Run start sent from external source, same for the cnc clock

Run start sent to through concentrator, concentrator clock from external source

STARTRUN_TDL_GPS 

Run start sent from GPS PPS signal

STARTRUN_CHAIN_T0 

Run start sent to board 0 and propagate in daisy chain through T0-out/T0-in

STARTRUN_CHAIN_T1 

Run start sent to board 0 and propagate in daisy chain through T1-out-T1-in
