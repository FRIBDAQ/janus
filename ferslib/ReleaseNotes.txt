Release 2.0.0 - 26/02/26
-------------------------------------------------------------------------------------------------------------------------
- Added support for multi-concentrator synchronization in configuration Master-Slave, or with an external system 
- Added FERS_isCncMaster function to get the Master/Slave status of the concentrators
- Added FERS_SendDCommandBroadcast and FERS_SetDCommandBroadcast functions to manage the broadcast commands across multiple concentrators
- Introduced FERS_SetCncCmdTrgSource function to configure the signal source that triggers command execution in SetDCommandBroadcast
- Divided TDL initialization into two functions: FERS_EnumTDLchains (enumeration) and FERS_SyncTDLchains (timing synchronization)
- Added new options for StartRunMode: 
     TDL_EXTRUN (start from external signal), 
     TDL_GPS (start from GPS, clock from GPS on CLK IN) 
- Added ExtRunSource to select the external start signal
- Increased timeout for readout completion of events
- Minor bug fix during close device process
- Improved logging system for error reporting
- Bug fix in test pulse setting
